# 대화 흐름과 정리·배포 요구사항

이 부록은 접근 가능한 현재 대화의 주요 질문과 작업 지시를 순서대로 정리한 것이다. 반복된 진행 보고는 성공 증거로 취급하지 않는다. 앞선 잘못된 농약 설명을 실제 사용 지침으로 재사용하지 않도록 본문의 정정표와 연결한다. 이 문서는 축약 없이 복제한 채팅 내보내기 파일이 아니라, 논점과 지시사항을 빠짐없이 묶은 대화 기록이다.

| 순서 | 사용자 제공 자료·질문 | 본문에서 다시 정리한 내용 |
|---|---|---|

## D. 기존 답변에서 재사용하면 안 되는 주장

본문 7절의 정정표가 우선한다. 단골의 잘못된 3성분 설명, 제품 함량을 제초력 순위로 바꾼 설명, 20L 사용량의 일괄 적용, 들깨·참깨를 콩과로 묶은 분류, 스톰프·라쏘의 들깨 사용을 근거 없이 허용한 설명은 폐기한다.

단골에 대해서는 최신 확인 자료를 별도로 반영한다. 제조사 SB성보 안내는 벤타존소듐 30% + 페녹사프로프-피-에틸 1%이며, 들깨(씨)·콩의 적용과 휴간 처리, 작물에 묻을 때의 약해 주의가 함께 제시되어 있다. ‘들깨 사용 근거가 전혀 없다’고 바꾸어 단정하는 것도 피한다.

## E. 기록하지 않은 사항

이 대화에 없는 실제 살포일, 살포 면적, 재배지 주소, 사용자의 멀칭 여부, 구매 여부와 구매 금액을 만들어 넣지 않는다. 사진의 매대 가격을 현재 시세라고 쓰지 않는다. 존재하지 않는 영상·오디오·PDF를 첨부 수에 포함하지 않는다. 원본 JPEG와 웹 최적화본은 파일명·해시·상태를 분리한다.
