# 농기계·굴착기면허·소형건설기계조종면허

굴착기 자격증과 조종사면허의 차이, 3톤 미만 교육 경로, 농기계에 적용할 때 확인할 사항을 모은 농업·농사 공개 아카이브입니다. 첨부 안내문과 공식 출처를 대조한 정리 내용을 함께 보관합니다.

## 자격증과 면허증의 차이

**굴착기운전기능사 국가기술자격증과 건설기계조종사면허증은 서로 다른 서류입니다.** 자격 취득 또는 해당 소형건설기계 교육을 이수한 뒤, 시·군·구의 면허 발급 절차를 진행합니다. 교육이수증만으로 면허 발급까지 완료된 것은 아닙니다. [근거 1·2]

| 구분 | 기능사 자격을 통한 경로 | 3톤 미만 굴착기 교육 경로 |
|---|---|---|
| 준비 단계 | 굴착기운전기능사 국가기술자격 취득 | 지정 교육기관의 해당 소형건설기계 조종교육 이수 |
| 교육 시간 | 자격시험 준비 과정과 일정에 따라 다름 | 이론 6시간 + 실습 6시간, 총 12시간 [근거 3] |
| 이후 절차 | 자격 확인 및 면허 발급 요건을 갖추어 시·군·구에 신청 | 교육이수증 및 면허 발급 요건을 갖추어 시·군·구에 신청 |
| 구분할 면허 종류 | 굴착기 | 3톤 미만의 굴착기 |
| 중량 확인 | 장비와 면허 종류를 대조 | ‘3톤 이하’가 아닌 ‘3톤 미만’. 굴착기 교육 규격은 자체중량 기준 [근거 2·3] |
| 일정 해석 | 시험 합격일과 면허 발급일은 별개 | 원문의 ‘2일 완성’은 교육 일정 표현이며 면허 발급 완료를 보장하지 않음 |

이 표는 **건설기계로 분류되는 굴착기의 면허 경로**를 정리한 것입니다. 농업기계 범위에 해당하는 장비는 기종과 법적 분류를 별도로 확인합니다. 굴착기 면허를 지게차·로더 등 모든 건설기계에 공통으로 적용하는 것으로 읽으면 안 됩니다.

## 실제 준비 순서

1. **사용할 장비를 먼저 확인합니다.** 기종, 형식, 자체중량, 등록·분류 자료로 농업기계인지 건설기계인지 구분합니다.
2. **해당 경로를 선택합니다.** 건설기계인 3톤 미만 굴착기라면 지정 교육 이수 경로를, 일반 굴착기 면허를 준비한다면 국가기술자격 경로를 확인합니다.
3. **면허 발급 절차를 마칩니다.** 교육이수증 또는 자격 정보와 사진·신체검사 관련 서류 등은 접수기관의 최신 안내에 맞춥니다. [정부24 민원 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=15000000380)
4. **임대할 기종의 조건을 별도로 확인합니다.** 임대사업소에 장비명, 필요한 면허 종류, 교육 이수, 보험 등 대여 요건을 확인합니다. 이 자료에는 서산시 임대 가능 여부나 교육 신청 완료 사실이 없습니다.
