# 박 노지재배: 적심·아들줄기·꽃 관리

| 항목 | 관리 요령 |
|---|---|
| 원줄기 적심 | 필수 아님. 곁줄기 생장을 촉진하기 위한 선택적 관리 |
| 적심 시기 | 본잎 5~7매 전개 시 생육 상태·품종에 따라 검토 |
| 적심 위치 | 남길 잎과 곁눈 위의 생장점 제거 |
| 아들줄기 | 적심하지 않아도 발생 가능 |
| 수꽃 | 꽃가루 공급을 위해 유지 |
| 암꽃 | 착과용으로 유지. 과다 착과 시 조절 |

![박 생육 사진](images/bak_growth.jpg)

사진상 아들줄기가 뚜렷하게 발달하지 않은 것으로 보이며, 정확한 본잎 수와 절단 위치는 현장 확인이 필요합니다.

## 작업 순서
1. 떡잎을 제외한 본잎 수 확인
2. 적심을 선택하면 곁눈을 남기고 생장점 제거
3. 아들줄기 생장 관찰 및 유인
4. 수꽃 유지, 암꽃 착과 관리

> 박의 종류와 재배 목적에 따라 적심 방법은 달라질 수 있습니다.
