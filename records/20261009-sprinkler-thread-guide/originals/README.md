# 스프링클러 배관 나사 규격 정리

정리일: 2026-10-09

## 핵심 결론

| 배관 나사 호칭 | 배관 호칭 | 수나사 바깥지름(대략) | 온라인 판매에서 흔한 표기 |
|---|---:|---:|---|
| 1/2″ | 15A | 약 20.9mm | 20mm / 2.0cm급 |
| 3/4″ | 20A | 약 26.4mm | 25mm / 2.5cm급 |
| 1″ | 25A | 약 33.2mm | 32~33mm급 |

- **1/2″ = 실제 나사 외경 12.7mm가 아닙니다.**
- 배관 나사의 인치 표기는 **호칭**이며 실제 수나사 외경은 더 큽니다.
- **1/2″ 수나사 외경은 약 20.9mm**입니다.
- **3/4″ 수나사 외경은 약 26.4mm**입니다.
- **1″ 수나사 외경은 약 33.2mm**입니다.
- 판매 페이지의 **2.0cm형은 1/2″ 쪽**, **2.5cm형은 3/4″ 쪽**으로 보는 것이 맞습니다.
- 판매자가 `2.5cm / 1inch`처럼 적은 경우 단순 길이 환산을 혼용했을 가능성이 있어 **표준 배관 나사 호칭과 일치하지 않을 수 있습니다.**

## 암나사·수나사 관계

나사산은 봉우리와 골이 반복되므로 측정 위치에 따라 지름이 달라집니다.

- **수나사**: 나사산 봉우리의 가장 바깥쪽끼리 잰 최대 외경이 약 20.9mm(1/2″ 기준)
- **암나사**: 수나사의 봉우리가 들어가는 골 쪽 최대 내부 직경은 같은 호칭에 맞게 형성
- 암나사 입구에서 튀어나온 나사산 봉우리끼리 재면 20.9mm보다 작게 측정될 수 있음
- 쉽게 말하면 **수나사의 산이 암나사의 골에 들어가 맞물리는 구조**입니다.

따라서 연결할 때는 **1/2″ 수나사 ↔ 1/2″ 암나사**처럼 같은 호칭끼리 연결하면 됩니다.

## 이번 제품 비교

### 첫 번째 제품
- 상품 표기: **1/2인치 외부 나사산**
- 해석: **1/2″ 수나사**
- 실제 수나사 바깥지름: 약 **20~21mm**

### 두 번째 제품
- 옵션 1: **2.0cm 스프링클러** → 사실상 **1/2″ 쪽**
- 옵션 2: **2.5cm 스프링클러** → 사실상 **3/4″ 쪽**

따라서 처음 제품과 같은 크기를 고른다면 **두 번째 제품에서는 2.0cm 옵션**이 대응합니다.

## 구매 시 확인사항

1. 가능하면 판매자 표기의 `20mm`, `25mm`보다 **1/2″, 3/4″ 같은 배관 호칭을 우선 확인**
2. 실측 시 수나사 바깥지름 확인
   - 약 20~21mm → 1/2″ 가능성 높음
   - 약 26mm 전후 → 3/4″ 가능성 높음
   - 약 33mm 전후 → 1″ 가능성 높음
3. PT/BSP 계열과 NPT 등은 나사 형식·피치가 다를 수 있으므로 규격표를 함께 확인
