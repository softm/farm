## 암나사·수나사

나사산은 봉우리와 골이 반복되므로 재는 위치에 따라 값이 달라진다. 1/2″ 수나사의 나사산 최대 외경은 약 20.9mm이고, 이에 맞는 연결 부품은 1/2″ 암나사다. 즉 **수나사의 산이 암나사의 골에 들어가 맞물리는 구조**로 이해하면 된다.

## 구매 시 확인

1. 가능하면 20mm·25mm 같은 판매자 표기보다 **1/2″·3/4″ 같은 배관 호칭을 우선 확인**
2. 실측 보조: 20~21mm → 1/2″, 26mm 전후 → 3/4″, 33mm 전후 → 1″
3. PT/BSP와 NPT 등 나사 방식·피치도 확인
