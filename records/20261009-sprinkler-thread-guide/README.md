## 암나사·수나사 관계

나사산은 봉우리와 골이 반복되므로 측정 위치에 따라 지름이 달라진다.

- **수나사**: 나사산 봉우리의 가장 바깥쪽끼리 잰 최대 외경이 약 20.9mm(1/2″ 기준)
- **암나사**: 수나사의 봉우리가 들어가는 골 쪽 최대 내부 직경은 같은 호칭에 맞게 형성
- 암나사 입구의 나사산 봉우리끼리 재면 최대 직경보다 작게 측정될 수 있음
- 연결은 **1/2″ 수나사 ↔ 1/2″ 암나사**처럼 같은 호칭끼리 맞춘다.

## 구매 시 확인

1. `20mm`, `25mm`보다 **1/2″, 3/4″ 같은 배관 호칭**을 우선 확인
2. 실측 보조: 20~21mm → 1/2″, 26mm 전후 → 3/4″, 33mm 전후 → 1″
3. PT/BSP 계열과 NPT 등 나사 방식·피치도 확인
