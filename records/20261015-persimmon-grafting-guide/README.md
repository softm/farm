## 핵심 요약

1. 접수는 눈이 움직이기 전인 1월 하순~2월 10일 무렵에 채취합니다.
2. 잎눈이 많고 굵기 9mm 이상인 1년생 가지를 고릅니다.
3. 젖은 수건 또는 신문지로 감싼 뒤 비닐에 완전히 밀봉하여 0~5℃에서 보관합니다.
4. 접목 직전 눈의 생존 여부를 확인하고, 눈 배치에 맞춰 접수를 대체로 5~7cm로 조제합니다.
5. 대목 절단면을 반듯하게 다듬고 접수의 한쪽 면을 맞춘 뒤 접목테이프로 단단히 결속합니다.
6. 마지막에 노출된 절단면을 도포제로 막고, 고라니 등이 접목부를 건드리지 않도록 주변에 가지를 꽂습니다.
